05 / System Design

Technical Architecture

A server-rendered Django application separates request handling, managed portfolio content, and static delivery so each part has a clear role.

01 / Request

Visitor & Vercel

A browser request reaches the Vercel deployment, which invokes the Django WSGI application for the requested page.

02 / Application

Django routing & rendering

URL patterns dispatch to views. Views load the needed content, and Django templates render the response as server-side HTML.

03 / Content

Admin & database

Authorized edits in Django Admin update portfolio models. Production uses MySQL through DATABASE_URL; local development can use SQLite.

04 / Delivery

Static assets

The deployment build applies Django migrations and runs collectstatic. Vercel serves the collected CSS, JavaScript, fonts, and resume file.
